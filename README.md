# 介護売上管理アプリ（プロトタイプ）

介護事業者向けの売上管理アプリ。ブラウザ単体で動作し、データはブラウザ内（localStorage）に保存されます。

## 使い方

`kaigo-app/index.html` をブラウザで直接開くだけで動きます。インストール不要。

または簡易サーバーで起動：
```bash
cd kaigo-app
python3 -m http.server 8000
# → http://localhost:8000 をブラウザで開く
```

## 画面

1. **ダッシュボード** — 当月売上、前月比、サービス別・利用者別集計
2. **売上入力** — 月単位 / 日単位を切替。「先月分をコピー」で月初の入力を省力化
3. **利用者** — 利用者マスタの登録・削除
4. **サービス分類** — 訪問介護・通所介護など、自由に追加・削除可能

## 最小操作のしくみ

- 利用者・分類を1回登録すれば、毎月の入力はプルダウン選択 + 金額のみ
- 「先月分をコピー」ボタンで、定期利用者の当月雛形を1クリック生成
- 月末にダッシュボードから「Excel出力」で税理士提出用ファイルを生成（明細・利用者別・サービス別の3シート）

## データ保存について（現状）

- 当アプリは現時点で **ブラウザのlocalStorageに保存** します
- 同じPC・同じブラウザでしか見えません（情報は外部に出ません）
- データのバックアップは将来のExcel出力 or 別途エクスポート機能で対応予定

## 今後の拡張余地

- 複数PC共有 → 社内サーバー or クラウドDB（Supabase等）への切替
- ユーザー認証
- 月締めロック機能
- 介護保険・自費の区分管理
- 詳細な単価計算（単位数×地域単価）
