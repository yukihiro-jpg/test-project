============================================================
  現金出納帳・仮払管理システム
  税理士事務所用ランチャー（最新版を起動.bat）
============================================================

このフォルダの「最新版を起動.bat」は、税理士事務所の業務用PCで
使うことを想定したものです。
ダブルクリックするだけで:

  1. GitHub から本番ブランチ（app/cash-ledger-with-bank-csv）の
     最新版を取得し、
  2. Chrome / Edge のアプリモードで cash-ledger-app/index.html を起動

します。修正をリポジトリにマージすれば、次回起動時には自動的に
反映されます。


------------------------------------------------------------
  事前準備（最初の1回だけ）
------------------------------------------------------------

1. Git for Windows をインストール
   https://git-scm.com/download/win

2. このリポジトリを「業務専用」のフォルダにクローン
   （手元で編集すると pull に失敗する場合があるため、開発用とは
    別の場所にクローンしてください）

      例: C:\Users\<ユーザー名>\Documents\cash-ledger-prod

      git clone <リポジトリのURL> C:\Users\<ユーザー名>\Documents\cash-ledger-prod

3. クローンしたフォルダ内の
      cash-ledger-app\dev-launcher\最新版を起動.bat
   を右クリック → 送る → デスクトップ（ショートカットを作成）
   でデスクトップに起動アイコンを置いてください。


------------------------------------------------------------
  日々の使い方
------------------------------------------------------------

デスクトップのショートカットをダブルクリックするだけです。

  * インターネット接続があれば: 最新版を取得して起動
  * インターネット未接続のとき: ローカルの内容で起動

データ（localStorage / IndexedDB）は file:// のパスごとに保持
されるため、index.html のパスが変わらない限り消えません。
このランチャーは常に同じパスを使うので、データは保持されます。


------------------------------------------------------------
  顧問先のPCにも入れたい場合
------------------------------------------------------------

顧問先には、このランチャーではなく
  cash-ledger-app/installer/インストール.bat
を含む ZIP を配布してください。
（顧問先には Git やネット通信なしで動く方が安全です）


------------------------------------------------------------
  トラブルシューティング
------------------------------------------------------------

* 「pull に失敗しました」と出る:
    業務用クローンに手元の変更が入っている可能性があります。
    git status で確認し、不要な変更は git restore で戻してください。

* 「fetch に失敗しました」と出る:
    ネットワーク or GitHub 認証エラーです。
    一旦ローカルの内容で起動するので、業務は止まりません。
    後で git pull を手動で試してください。

* 「git が見つかりません」と出る:
    上の「事前準備」の手順1で Git for Windows を入れてください。

* Chrome も Edge も入っていない場合:
    既定のブラウザで開きます（アプリモードにはなりません）。
