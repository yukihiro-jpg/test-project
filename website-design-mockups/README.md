# KSK会計事務所 — Webデザイン案モックアップ

kskac.jp のリニューアル検討用に、**同一コンテンツ・同一写真構成のまま**デザインの方向性だけを変えた3案の静的モックアップです。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 3案をタブで切り替えて比較できる確認用ビュー（ここから開くのが便利） |
| `design-google.html` | ① **Googleイメージ案** — Material Design 風。明るい余白＋4色アクセント |
| `design-tax-modern.html` | ② **税務法務系モダン案** — ネイビー×ゴールド＋明朝。信頼・格調重視 |
| `design-flower.html` | ③ **花屋さんイメージ案** — セージ×テラコッタ。曲線と余白でやわらかく |

## 見方

`index.html` をブラウザで開くと、タブで3案を切り替えながら比較できます。各HTMLは単体でも開けます（依存パッケージなし・ビルド不要）。

## 共通コンテンツ（全案で同一）

トップ／サービス（税務顧問・確定申告・相続・会社設立・経営コンサル・給与計算）／選ばれる理由／ご相談の流れ／料金プラン（ライト・スタンダード・フルサポート）／代表挨拶／お問い合わせ。

## 注意（差し替え前提のプレースホルダー）

- **文章**：元サイト（kskac.jp）へ本環境のネットワーク制限で直接アクセスできなかったため、税務・会計事務所として一般的な代表内容で組んでいます。実際の文言に差し替え可能です。
- **写真**：ブラウザ表示時に読み込まれるプレースホルダー画像（Unsplash CDN）を使用。実写真に差し替え可能です。
- **会社名・住所・電話・料金**：すべて仮の値（`○○`・`000-...`）です。

方向性が決まれば、その案をベースに実コンテンツ・実写真へ調整します。

## 既存アプリへの影響

`CODEX_RULES.md` の方針に従い、このディレクトリ内のみで完結しています。`src/` や `package.json` 等の既存ファイルは変更していません。
